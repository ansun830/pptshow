# 基准方中 · 企业级高保真建筑方案演示云平台
### JZFZ Architectural Presentation Cloud & Auto-Sync System (白石画廊极简版)

专为建筑设计大院与方案汇报打造的轻量级 Web 协同演示系统。
针对建筑超大图纸、异地多方方案提问沟通、知识产权防盗保护等实际痛点深度重构。

---

## 🌟 核心特性总览

### 1. 集团官方视觉与白石画廊纯白极简 (CI & Stage-First Design)
* **基准方中品牌体系深度整合**：官方标准红印章（建筑结构线“基”字标）、“基准方中”标准字与企业标语“基于心 · 准于行 | 创造价值 · 成就梦想”高清矢量呈现。
* **舞台优先 (Stage-First Architecture)**：彻底移除侵占视口的固定顶栏，视口 100% 留给建筑图纸。
* **悬浮智能毛玻璃 Dock (底部灵动胶囊 - Apple/Figma 风格)**：控件集中在底部悬浮胶囊中，鼠标静止 2.5 秒后自动淡化隐退，图纸全屏纯净无遮挡，触碰即唤醒。
* **胶片式画廊抽屉 (Bottom Filmstrip Drawer)**：底部横向滑出高清缩略图，一键秒级跳页。

### 2. 异地双向协同圈点 (领导/客户提问画笔)
* 参会领导或客户可在观众端一键开启【提问圈点画笔】（鲜明提问蓝 `#2563eb`），直接在图纸上画圈提问。
* 主讲人屏幕毫秒级呈现圈选笔迹，并伴随微提示条（`💬 参会嘉宾正在圈点提问...`），主讲人一键清屏，异地沟通如同围坐在同一张图纸前。

### 3. 客户防盗与受控保护 (限次、限时、体面微提醒、专属水印)
* **阅览次数与时效控制**：发给客户提前看方案时，可设定打开次数（如限 10 次）和截止时间（如 72 小时）。
* **体面微提示徽标**：客户界面小巧显示 `🛡️ 受控审阅版 · 限阅 10 次 (剩余 6 次) · 截止 10/05 18:00`，字小且体面，提醒客户受控审阅，防止私下随意转发。
* **基准方中防盗浅水印**：倾斜阵列平铺半透明红印水印，不影响正常读图，但手机拍照或电脑截屏时水印清晰显现，有效形成版权与心理震慑。
* **超次/到期体面锁定屏**：达到阅览上限或过期后，自动进入白石画廊锁定页，促使客户主动联系团队深化沟通。

### 4. 建筑空间漫游与多层次动效引擎
* **建筑漫游巡镜 (Ken Burns)**：对 4K/8K 鸟瞰渲染大图进行电影级缓慢推拉与镜头微移，静态图纸秒变建筑宣传片。
* **漫游视频多端毫秒级同步**：支持 MP4/WebM 三维漫游视频，主讲人播放/暂停/拖动进度，所有观众端手机与电脑毫秒级同步看同一帧。
* **自动巡展展厅模式**：适用于总部大堂展屏或投标等待室，每隔 8 秒自动平滑翻页循环播放。

## ⚡ 自动化代办更新与“保存即同步”监听守护

告别繁琐的“另存为 -> 打开浏览器 -> 找到房间 -> 点击换稿 -> 重新上传”流程！

### 方式 1：直接吩咐 AI 助手代办（零操作体验）
在对话中直接告诉 Gemini Spark：
> *“帮我把桌面上最新的方案 PPT 推上去”* 或 *“把刚刚修改好的立面图纸换上去”*

AI 助手将自动在后台调用 `auto_sync.py push` 完成文件读取、智能压缩、服务器版本替换与全网观众端无感刷新！

### 方式 2：“保存即同步”守护进程 (Save-to-Sync Daemon)
在终端中启动监听：
```bash
python3 auto_sync.py watch /path/to/your/scheme.pptx
```
* **效果**：您在 PowerPoint 或 Keynote 里只要按一下快捷键 **`Cmd + S`（保存）**，后台守护程序毫秒级检测到文件变动，自动把新版推送到当前的放映房间！
* 异地参会的客户和领导在您按下保存的瞬间，屏幕上立刻自动刷新成最新方案图纸，并伴有 macOS 原生桌面推送通知。

## 🚀 启动与部署

### 本地 / 云服务器运行 (Python 零依赖极速模式)
```bash
cd slide-cast
python3 app.py 8080
```
或使用 Node.js 版本：
```bash
npm start
```

访问 `http://localhost:8080` 即可开始演示。
本地预览中心：直接在浏览器打开 `public/preview.html` 体验全量实景与交互。
